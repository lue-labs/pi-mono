- **Persistent-fork lifecycle primitive + `AgentHandle.resume`/`inject` seam (CC 2.1.201 observer-agent enablement, Slice E core).** Adds the minimal core primitive an out-of-tree extension needs to run a CC-faithful long-lived background observer (a background subagent fed digests turn-after-turn), which pi's fork machinery could not express because a completed background run was terminal (controller deleted, session retired). New optional `ForkAgentOptions.persistent?: boolean` (default unset = unchanged terminate-on-completion): when a single background fork is `persistent`, it now **parks as `"interrupted"` after each turn instead of `"completed"`** — the only non-running status that `status.ts` keeps the run controller alive for (`applyRunDetails` deletes the controller on completed/cancelled/failed only) and that `canResumeRun` accepts (interrupted + mode single + execution background + a persisted `sessionPath`). The launcher feeds the next turn with the new `AgentHandle.resume(message)` (reloads the disk-persisted child session via `resumeSingleBackgroundRun` → cross-turn history preserved) and can steer a mid-turn child with `AgentHandle.inject(message)` (session.steer; rejects when the fork is parked/idle with no active session); both were added to the `AgentHandle` interface in `core/extensions/types.ts` and implemented in `core/agents/engine.ts` over the existing `resumeAgentRecentRun`/`injectAgentRecentRun` control functions (throw on `!result.ok`). The park is implemented in `core/agents/executor.ts` via a single `isPersistentPark(input)` helper (`persistent === true && background === true && mode === "single"`) applied at both single-run completion sites; the subtle part is that the child completing emits a `"completed"` progress aggregate through `makeBackgroundOptions.onProgress` → `updateAgentRecentRunProgress`, which would mark the run terminal and delete its controller *before* the park runs — so for persistent runs that terminal `"completed"` progress is remapped to `"running"`, making the park's `finishAgentRecentRun(interrupted)` the sole terminal transition (controller retained, `resumable` true, waiters resolve on interrupted). `abort()` still retires a parked fork (cancel is valid on interrupted → `"cancelled"`).
